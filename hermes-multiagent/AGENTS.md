# Контекст проекта

## Проект

Это учебный Python-проект для изучения миграции зависимостей и агентной разработки.

Корень проекта:

`C:\Users\user\Desktop\аис\ии2\hermes-multiagent`

## Окружение

Проект использует Python.

Виртуальное окружение находится в `.venv`.

Тесты запускаются командой:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Основное приложение запускается командой:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Общие правила

Перед изменением файлов сначала изучай текущую реализацию и требования задачи.

Сохраняй существующее внешнее поведение программы, если задача явно не требует его изменения.

Не выполняй несвязанный рефакторинг.

Не удаляй существующие тесты ради прохождения проверки.

Не добавляй новые runtime-зависимости без прямой необходимости.

## Правила Git

Разрешено использовать `git status` и `git diff` для анализа изменений.

Не выполняй `git push`.

Не создавай коммит без прямого указания пользователя.

Не изменяй историю Git.

## Безопасность

Не открывай и не выводи содержимое файлов с секретами, токенами и паролями.

Не изменяй `.env` и другие файлы с секретами.

Не выполняй разрушительные команды над файловой системой.

Если действие выходит за пределы текущей задачи, остановись и сообщи об этом пользователю.

## RAG кодовой базы

При вопросах о структуре, связях, бизнес-логике, зависимостях, API и потенциально затрагиваемых файлах сначала используй `codebase_search`.

Не делай вывод о кодовой базе по одному фрагменту.

Если результатов недостаточно, повтори поиск с уточнённым запросом.

В ответе указывай пути файлов, на которых основан вывод.
