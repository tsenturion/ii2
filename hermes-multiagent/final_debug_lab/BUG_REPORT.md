# BUG-001. Ошибка при создании возврата для старого заказа

## Окружение

Локальное учебное Python-окружение проекта.

## Наблюдаемая проблема

При создании заявки на возврат для некоторых старых заказов операция завершается ошибкой. Новые заказы с аналогичными товарами обрабатываются нормально.

## Пример

Для заказа 1001 заявка на возврат создаётся. Для заказа 1002 при тех же параметрах возврата возникает ошибка.

## Ожидаемый результат

Для обоих доставленных заказов должна создаваться заявка на возврат со статусом `requested`.

## Фактический результат

Заказ 1001 обрабатывается успешно. Заказ 1002 завершается ошибкой.

## Воспроизводимость

Для заказа 1002 проблема воспроизводится при каждом запуске.

## Дополнительная информация

Заказ 1002 относится к данным, перенесённым из старой версии системы. Точная причина ошибки неизвестна.
