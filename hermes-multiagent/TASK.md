# Задача миграции

Проект использует Pydantic 1.x.

Необходимо перейти на Pydantic 2.x.

Требования:

- изменить зависимость на `pydantic>=2,<3`;
- заменить устаревшие API Pydantic v1 на рекомендуемые API Pydantic v2;
- сохранить сигнатуру `serialize_user(data)`;
- сохранить внешний результат работы функции;
- сохранить проверку минимального возраста;
- существующие тесты должны проходить;
- не добавлять новые runtime-зависимости;
- не выполнять несвязанный рефакторинг.
