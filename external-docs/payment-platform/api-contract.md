# Контракт API Billing Bridge

Актуальный внутренний контракт платёжного сервиса.

## Обязательный заголовок

Каждый запрос Billing Bridge должен содержать заголовок:

```text
X-Payment-Contract: 2026-09
```

## Создание платежа

Операция создания платежа принимает:

- `order_id` — идентификатор заказа;
- `amount` — сумму платежа;
- `currency` — код валюты.

Для текущего проекта используется `currency = RUB`.

## Ответ

Успешный ответ содержит:

- `payment_id`;
- `order_id`;
- `status`;
- `created_at`.

## Обработка ошибок

- HTTP 409 означает конфликт состояния платежа. Такой запрос нельзя повторять
  автоматически.
- HTTP 429 допускает повтор после задержки, указанной сервером.
- HTTP 500 допускает не более двух автоматических повторов.

## Устаревший контракт

Контракт `X-Payment-Contract: 2025-11` считается устаревшим.
