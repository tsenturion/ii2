# Политика миграции

Документ определяет актуальные правила миграции на Billing Bridge.

## Объём миграции

Миграция выполняется по отдельным сервисам. Запрещено одновременно переписывать
всю платёжную подсистему. На каждом этапе необходимо сохранять внешний контракт
приложения.

## Окно выпуска

Изменения платёжного клиента разрешено выпускать в production только по средам
с 02:00 до 03:00 UTC.

## Обязательные проверки

Перед production deployment должны успешно завершиться unit-тесты и
integration-тесты платёжного модуля. Также должна быть выполнена проверка
совместимости с текущим checkout API.

## Откат

Предыдущая версия платёжного клиента должна оставаться доступной для rollback в
течение 24 часов после deployment.
