# Глоссарий проекта

- Billing Bridge — текущая внешняя платёжная платформа.
- `BillingBridgeClient` — клиент приложения для обращения к Billing Bridge.
- `LegacyPaymentGateway` — устаревший платёжный клиент.
- `PaymentService` — внутренний сервис приложения, через который инициируются
  операции оплаты.
- `Checkout` — модуль оформления заказа.
- Payment Contract — версия соглашения о формате обмена данными между
  приложением и Billing Bridge.
