# Архитектура платёжной платформы

Документ описывает внутреннюю архитектуру учебной платёжной платформы.

## Текущий платёжный клиент

Рабочая система постепенно переходит со старого `LegacyPaymentGateway` на
`BillingBridgeClient`.

`LegacyPaymentGateway` считается устаревшим и не должен использоваться в новых
модулях.

Целевой клиент для нового кода — `BillingBridgeClient`.

Основной сервис обработки платежей должен обращаться к `BillingBridgeClient`
через слой `PaymentService`.

Прямой вызов `BillingBridgeClient` из модуля `checkout` запрещён.

## Ответственность компонентов

- `Checkout` отвечает за оформление заказа.
- `PaymentService` отвечает за инициирование платежа.
- `BillingBridgeClient` отвечает только за взаимодействие с внешней платёжной
  платформой.
- Модули уведомлений не должны напрямую обращаться к платёжному клиенту.
